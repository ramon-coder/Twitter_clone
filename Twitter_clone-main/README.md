# Twitter Clone

Un clon de Twitter con autenticación y funcionalidad de tweets.

## Características

- Registro e inicio de sesión
- Autenticación con credenciales, GitHub y Google
- Crear tweets (hasta 280 caracteres)
- Feed de tweets
- Like y retweet
- Perfil de usuario

## Instalación

1. Clona el repositorio
2. Instala dependencias:
```bash
npm install
```

3. Configura las variables de entorno (copia `.env.example` a `.env.local`)

4. Ejecuta el servidor de desarrollo:
```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) con tu navegador.
